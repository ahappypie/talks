# Spot Markets

<ul>
    <li v-click="1">Compute is <b>perishable</b>, an unallocated CPU cycle loses <span text-red>100%</span> of its value if it sits idle</li>
    <li v-click="2">Providers sell excess capacity at steep discounts up to 70-90% off on-demand rates</li>
    <li v-click="3">In exchange, the provider reserves the right to reclaim instances with short notice if demand surges</li>
</ul>
