# Creating Value from Internal Data

<div text-sm>
<ul>
<li v-click="1">Many organizations have a customer data strategy</li>
<li v-click="2">Fewer take advantage of data from within their organization</li>
</ul>
</div>
<div mt-2 text-sm>
<h4 v-click="3">Otis Elevator</h4>
<ul>
<li v-click="4">Maintenance tech visits → identifies problem → orders part → comes back next week</li>
<li v-click="5">Otis collected data on their elevators starting in 1988, but never applied predictive modeling</li>
<li v-click="6">Converted sensor logs like door cycle speeds, vibration patterns, and motor temperature into health scores using machine learning</li>
<li v-click="7">Algorithms flag failing part, techs arrive with the replacement part before the elevator fails</li>
</ul>
</div>
<div mt-2 text-sm>
<h4 v-click="8">Your Task</h4>
<ul>
<li v-click="9">Identify internal data in your organization (or life)</li>
<li v-click="10">Create an implementation plan:</li>
<li v-click="11">Where is the data? How will you collect it?</li>
<li v-click="12">What transformation does it need to become valuable? (hint: many times we need to pair multiple datasets together!)</li>
<li v-click="13">How will you present this value to your users? (hint: who is your user?)</li>
</ul>
</div>
